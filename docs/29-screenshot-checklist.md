# TAMIAS — Portfolio Screenshot Checklist

## Purpose

Use this checklist to capture screenshots for the portfolio version of TAMIAS.

Recommended environment:

```text
https://tamias.juantzun.dev
```

Do not capture screenshots from production if they contain real guest/property data.

---

## Screenshot rules

```text
Use testing/portfolio environment
Use demo data only
Avoid real guest names
Avoid real phone numbers
Avoid real emails
Avoid real invoices or personal documents
Avoid secrets in browser/devtools
Use consistent browser width
Prefer light mode unless dark mode is intentionally part of the design
```
