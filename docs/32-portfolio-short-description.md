# TAMIAS — Portfolio Short Description

## Project title

```text
TAMIAS — Property Operations Platform
```

## One-line description

```text
A full-stack SaaS-style platform for managing small lodging properties, including maintenance, reservations, documents, file storage, and AI-assisted document search.
```

## Short card description

```text
TAMIAS is a SaaS-style property operations platform for small lodging businesses such as vacation homes, apartments, bungalows, and cabins. It centralizes maintenance, reservations, task lists, purchase lists, documents, AWS S3 file storage, and AI-powered document search using RAG.
```

## Technical card description

```text
Built with Java 21, Spring Boot 3, Angular, PostgreSQL, AWS S3, Spring AI, OpenAI, Chroma, Docker, GitHub Actions, Vercel, Render, Supabase, Railway, Docker Hub, and Cloudflare.
```

## LinkedIn project description

```text
TAMIAS is my full-stack SaaS-style platform for managing small lodging properties.

It includes authentication, role-based access control, organization-based data isolation, property management, maintenance records, scheduled maintenance, reservations, task lists, purchase lists, inventory items, document management, AWS S3 file storage, and an AI assistant powered by RAG.

The project is deployed in separated testing and production environments using Vercel, Render, Supabase PostgreSQL, AWS S3, Railway Chroma, Docker Hub, GitHub Actions, and Cloudflare.
```

## Problem / solution version

```text
Small lodging property managers often rely on spreadsheets, WhatsApp messages, folders, printed documents, and manual notes to track operations. TAMIAS centralizes these workflows into a single web platform and adds AI-assisted document search so users can quickly find information from house rules, manuals, policies, and operational documents.
```
